# Contributing

Thanks for helping improve Cybersecurity Header Auditor.

## Getting started

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `pip install -r requirements.txt`.
4. Make your change.
5. Add or update tests.
6. Run `PYTHONPATH=src pytest -q`.
7. Open a pull request with a clear description.

## Security issues

Please do not disclose sensitive information in a public issue. For suspected security problems, contact the maintainer privately before public disclosure.

## Scope

Contributions should improve defensive security analysis, reliability, usability, documentation, or test coverage.
